You are an expert in legal and corporate structuring, tasked with generating a high-quality dataset for training a specialized AI model called the Sapient HRM (Hierarchical Reasoning Model). Your goal is to produce a series of "flashcards" in NDJSON format that will be used to teach the AI how to reason about corporate structure design.

**Primary Objective:**
Generate 500 high-quality, diverse, and accurate flashcards in NDJSON format. Each line of your output must be a single, valid JSON object. Do not include any other text, commentary, or markdown formatting in your response.

**JSON Schema:**
Each JSON object (flashcard) must conform to the following schema:

{
  "input": {
    "jurisdiction": "string", // The country code for the legal jurisdiction (e.g., "za", "uk", "us").
    "scenario": "string",     // A realistic, 1-3 sentence description of a client's situation and needs.
    "assumptions": "string",  // A 1-sentence summary of key assumptions made about the client's situation.
    "constraints": "string",  // A 1-sentence description of any constraints or limitations.
    "goals": ["string"]       // A list of the client's primary objectives (e.g., "liability_protection", "tax_efficiency", "asset_protection").
  },
  "output": {
    "recommended_structures": ["string"], // A list of recommended corporate structures (e.g., "za_pty_ltd", "mu_ibc").
    "policy_refs": ["string"]             // A list of internal policy reference tags (e.g., "internal_policy:za_small_business_guidance_v1").
  },
  "meta": {
    "subsection": "string",      // A category for the flashcard (e.g., "za_simple_liability", "intl_simple_trade").
    "difficulty": "string",      // The difficulty of the scenario ("simple", "intermediate", "edge").
    "source_prompt_id": "string",// A unique identifier for the prompt that generated this flashcard. Use "P1_MASTER_01" for all cards.
    "rationale": "string",       // A clear, 2-4 sentence explanation of why the recommended structure is the best choice for the given scenario, assumptions, and goals. This is the most important part of the training data.
    "version": "string"          // The schema version, which should be "1.0".
  }
}

**Content Generation Guidelines:**

1.  **Diversity is Key:** Generate a wide variety of scenarios covering different industries (e.g., tech, consulting, retail, manufacturing), client types (e.g., solo founder, partnership, family business), and goals.
2.  **Jurisdictional Realism:** Ensure the scenarios and recommended structures are plausible for the specified jurisdiction. Use a mix of jurisdictions, including "za", "uk", "us", "mu", "de", and "ae".
3.  **Rationale is Critical:** The `rationale` is the most important field for training the AI. It must clearly and logically connect the `input` (scenario, goals) to the `output` (recommended structure). Explain the "why" behind the recommendation.
4.  **Vary Difficulty:** Create a mix of `simple`, `intermediate`, and `edge` case scenarios. Edge cases might involve conflicting goals, unusual constraints, or complex cross-border issues.
5.  **Adhere to the Schema:** Do not deviate from the JSON schema. Every field is required.

**Example Flashcard:**

{"input": {"jurisdiction": "za", "scenario": "An experienced plumber wants to expand his services and hire a team to handle larger contracts.", "assumptions": "The business is expected to grow significantly in the next year.", "constraints": "The owner wants to minimize personal liability for business debts.", "goals": ["liability_protection"]}, "output": {"recommended_structures": ["za_pty_ltd"], "policy_refs": ["internal_policy:za_small_business_guidance_v1"]}, "meta": {"subsection": "za_simple_liability", "difficulty": "simple", "source_prompt_id": "P1_MASTER_01", "rationale": "A Pty Ltd structure provides liability protection, shielding the owner's personal assets from business liabilities. This is the most appropriate structure for a growing business that will be taking on more employees and larger contracts, as it formally separates the business entity from the owner.", "version": "1.0"}}

Now, please generate exactly 500 flashcards following these instructions.
