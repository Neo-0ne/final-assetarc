Each JSON object must have three top-level keys: `input`, `output`, and `meta`.

**1. Input Schema:**
The `input` object must conform to the following structure, representing the assets of an individual.

```json

```

The `output` object must represent the result of the estate duty calculation, with "before" and "after" scenarios.

```json

    "executor_fees": "number",

  },
  "summary": {
    "total_savings": "number"
  }
}
```

**3. Meta Schema:**

```json
{
  "rationale": "string",
  "source_prompt_id": "P2_ESTATE_CALC_01"
}
```

**Content Generation Constraints (Very Important):**
1.  **Vary Scenarios:** Create a diverse set of scenarios. Include:
