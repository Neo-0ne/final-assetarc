You are a highly experienced senior legal architect and knowledge management expert. Your task is to create a foundational, structured library of legal clauses that will be used to train an advanced AI (the Sapient HRM) to assemble legal documents.

**Primary Objective:**
Generate a comprehensive list of common legal clauses, grouped by the type of document they typically appear in, based on the definitive list provided. The output must be a single JSON object containing a list of document types. Adhere strictly to the JSON schema provided below.

**JSON Output Schema:**
Your entire output must be a single JSON object with a root key named `document_clause_library`. This key should contain an array of "document" objects. Each document object must have the following structure:

```json
{
  "document_type": "string",
  "clauses": [
    {
      "clause_id": "string",
      "clause_name": "string",
      "description": "string"
    }
  ]
}
```

**Schema Field Definitions:**
*   `document_type`: The common name of the legal document (e.g., "Trust Deed", "Loan Agreement").
*   `clauses`: An array of objects, where each object represents a single, distinct clause.
*   `clause_id`: A unique, machine-readable identifier for the clause. Use the format `clause:<document_short_name>_<clause_name_snake_case>_v1`. For example, `clause:trust_deed_definitions_v1` or `clause:loan_agreement_interest_rate_v1`.
*   `clause_name`: The human-readable name of the clause (e.g., "Definitions", "Interest Rate and Payment").
*   `description`: A concise, one-sentence explanation of the clause's purpose.
